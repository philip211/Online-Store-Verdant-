## Симуляции и заглушки

| Что | Как на самом деле |
|---|---|
| Оплата | Провайдер не подключён. Заказ создаётся сразу, способ оплаты сохраняется строкой. Тексты «Payments are processed under PCI DSS with 3-D Secure» и «Payment confirmed» описывают, как должно быть |
| Статус заказа | Меняется по времени с момента оформления: < 1 мин — получен, < 3 мин — упакован, < 10 мин — в пути, дальше — доставлен (`statusForAge`) |
| Письма | Не отправляются: `apps/api/src/lib/mailer.ts` пишет их в лог. Тексты «чек и трек-номер придут на email» и квитанция отказа это учитывают только частично |
| Подписка | Нет регулярных списаний. Подписка — флаг, дающий −15% на этот заказ |
| Бонусные баллы | Начисляются 5% и показываются, но не списываются. «Двойные баллы за подписку» и «+200 за отзыв с фото» не реализованы |
| Аккаунты | Нет. «Мои заказы», избранное и корзина хранятся в браузере |
| PDF лабораторных отчётов | Кнопка показывает уведомление, файлов нет |
| Согласие на cookies | Сохраняется, но аналитики и маркетинговых скриптов в проекте нет |
| Дата доставки | Считается для Германии по местному времени браузера, а не по CET |

## Известные проблемы

1. **Заказы доступны без авторизации.**
   - `GET /api/orders/:id` отдаёт имя, адрес, телефон и email любому, кто знает номер заказа. Номер — 6 случайных
     цифр, его можно подобрать перебором (ограничение только общее: 300 запросов в минуту).
   - `GET /api/orders?email=` отдаёт все заказы по любому email.
   - Для рабочего магазина это утечка персональных данных. Исправление: отдавать заказ только по секретному токену из
     письма или после входа в аккаунт.
2. **Отзывы и «полезно» без защиты.** Отзыв публикуется сразу, «полезно» можно нажимать сколько угодно.
3. **Номера заказов** создаются через `Math.random` без проверки на совпадение.
4. **SEO.** Сайт рендерится только на клиенте: поисковики без JavaScript видят пустой `index.html`. Разметка
   `Product` всегда указывает `InStock`, даже при нулевом остатке.
5. **PWA.** Есть манифест с одной SVG-иконкой, но нет service worker и PNG-иконок.
6. **НДС** 19% для всех стран.

## Инженерные пробелы

- **Тестов нет:** ни юнит-, ни e2e-тестов, ни тест-раннера.
- **Скрипт `npm run lint -w @verdant/web` не работает:** ESLint не установлен и не настроен.
- **CI и Docker** не настроены.
- **Типы проверяются** во всех трёх пакетах в строгом режиме: `npm run typecheck`.
